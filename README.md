# SortForge · 排序锻造炉

单文件离线运行的排序算法动画实验台。6 种经典排序算法逐帧可视化比较/交换过程，实时统计比较与写入次数，并用确定性种子横向对比各算法效率。

> 同一种子 + 同规模 = 同一数组。把 6 种算法轮流跑一遍，谁快谁慢一目了然。

## 功能

- **6 种算法**：冒泡 · 插入 · 选择 · 快排(Quicksort) · 归并(Mergesort) · 堆排(Heapsort)
- **逐帧动画**：蓝色=未排序，黄色=正在比较，红色=交换/写入，绿色=已完成
- **实时计数**：比较次数、交换/写入次数、进度百分比
- **确定性种子**：输入任意文字/数字 + 规模，LCG 生成可复现数组
- **内置自检**：浏览器内一键验证 6 种算法正确性（边界 + 50 随机 + 一致性）

## 算法验证（无头）

引擎逻辑抽离为纯函数，`_smoke.js` 在 Node 下做不变量校验，**39/39 全绿**：

- 全部边界用例（空/单元素/已序/逆序/重复/负数）有序且元素多重集一致
- 已知小用例 `[3,1,2] → [1,2,3]`
- 50 个随机数组(30 项)全有序且元素一致
- 500 项随机、200 项低密度重复值正确
- 种子确定性：同种子同数组、异种子异数组
- 一致性：6 算法对同输入产出完全一致

示例（种子「晨星」size=40）实测计数：

| 算法 | 比较次数 | 交换/写入 |
|------|---------|----------|
| 冒泡 | 780 | 426 |
| 插入 | 462 | 465 |
| 选择 | 780 | 33 |
| 快排 | 241 | 90 |
| 归并 | 165 | 216 |
| 堆排 | 317 | 183 |

```bash
node _smoke.js      # 引擎不变量测试
node _probe.js      # 生成计数对照表到 _probe.txt
```
